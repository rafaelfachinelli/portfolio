# Cores

O Datum tem duas camadas: a **paleta** (cores brutas) e os **tokens semânticos**, que dizem para que cada cor serve. Componentes usam só os semânticos.

Cada cartão mostra o contraste da cor sobre o `color.board`. Texto precisa de 4,5:1 (AA).
