# Select

Escolher uma opção numa lista: ano, categoria, ordenação. Feito sobre o Select do Radix: abre com teclado, busca pela primeira letra, navega com as setas e é anunciado como lista pelo leitor de tela.

<Canvas of={SelectStories.Default} />

## Partes

| Parte                                           | Papel                                                                          |
| ----------------------------------------------- | ------------------------------------------------------------------------------ |
| `Select`                                        | O estado: valor, aberto ou fechado (`value`, `defaultValue`, `onValueChange`). |
| `SelectTrigger`                                 | O botão que mostra o valor. Recebe o `id` do rótulo; tamanhos `md` e `sm`.     |
| `SelectValue`                                   | O valor escolhido, ou o `placeholder`.                                         |
| `SelectContent`                                 | A lista, numa camada acima da página.                                          |
| `SelectItem`                                    | Uma opção. A escolhida fica na cor da temporada, com um visto.                 |
| `SelectGroup`, `SelectLabel`, `SelectSeparator` | Agrupam opções longas.                                                         |

## Quando não usar

- Até 4 opções que cabem na tela: botões de opção são mais rápidos (um clique em vez de dois).
- Listas muito longas (países, cidades): use um campo com busca.
