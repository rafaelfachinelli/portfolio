# Input

Um campo de texto de uma linha: nome, e-mail, busca. Para textos longos, use o [Textarea](?path=/docs/componentes-textarea--docs). Em formulários, prefira montar o campo com o [Field](?path=/docs/componentes-field--docs), que liga rótulo, ajuda e erro sozinho.

<Canvas of={InputStories.Default} />

<Controls of={InputStories.Default} />

## Tipos

Use o `type` certo: ele escolhe o teclado no celular (`email` mostra o @, `tel` mostra números) e ativa a validação do navegador.

## Acessibilidade

- Todo Input precisa de um rótulo ligado pelo `id` (o Field faz isso por você).
- O foco mostra a borda e um halo na cor da temporada.
- `placeholder` é só exemplo de formato: some quando a pessoa digita e tem contraste mais baixo.
